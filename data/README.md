# Data

Place `arxiv_ai_ml_papers.csv` here (or next to the notebook). It is not included in this repository.

Download: https://www.kaggle.com/datasets/shree0910/arxiv-aiml-research-papers-20252026

The notebook looks for the file in the working directory first. Set `FILE_PATH` in its first code cell to use this folder, for example `FILE_PATH = "../data/arxiv_ai_ml_papers.csv"`.
